# Rinc

Rinc is a small computer for making and playing little games, in the spirit of PICO-8. It boots in
an instant to a launcher and a console, and its programs, called carts, are written in
[Rio](https://contextfreeinfo.github.io/rio/). It runs on RP2350 boards (the Adafruit Fruit Jam first),
on the desktop, and in the browser, and a cart runs the same on all of them.

- **[Play the demo carts](https://rincpc.com/)** in a browser.
- **[Making carts](carts/README.md)** shows how, by example.
- **[The Rinc platform](spec/README.md)** says exactly what a Rinc provides, for carts and for anyone
  making another Rinc.
- **[The guide](guide/README.md)** covers this implementation: building it, the Fruit Jam, the
  desktop and the web.

Carts are Rio programs, so the [Rio docs](https://contextfreeinfo.github.io/rio/) cover the language.

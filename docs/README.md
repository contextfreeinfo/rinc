# Rinc

Rinc is a small computer for making and playing little games, in the spirit of PICO-8. It boots in
an instant to its home screen and a console, and its programs, called apps, are written in
[Rio](https://contextfreeinfo.github.io/rio/). It runs on RP2350 boards (the Adafruit Fruit Jam first),
on the desktop, and in the browser, and an app runs the same on all of them.

- **[Play the demo apps](https://rincpc.com/)** in a browser.
- **[Making apps](apps/first-app.md)** shows how, by example.
- **[The Rinc platform](spec/platform.md)** says exactly what a Rinc provides, for apps and for anyone
  making another Rinc.
- **[The guide](guide/building.md)** covers this implementation: building it, the Fruit Jam, the
  desktop and the web.

Apps are Rio programs, so the [Rio docs](https://contextfreeinfo.github.io/rio/) cover the language.
